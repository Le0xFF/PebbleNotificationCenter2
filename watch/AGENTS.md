# Pebble Notification Center: watch app

This folder contains the watch app for the implementation of the notification center for Pebble smartwatches.

## Compilation

To compile, execute the `CompilePWB.sh` in this same folder.

## Debbugging compilation

* Check `compile.log` in this same folder to see if compilation went fine.
* After checking, adjust the code accordingly, if needed.
